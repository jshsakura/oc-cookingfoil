CookingFoil

홈브류 클라이언트용 개인 파일 서버입니다.A self-hosted file server for homebrew clients.自作アプリ向けの個人用ファイルサーバーです。面向自制客户端的个人文件服务器。

집에 있는 컴퓨터에 내 파일을 두고, 파일에서 이름과 아이콘을 읽어 목록으로 내보냅니다. CyberFoil, Tinfoil 방식 클라이언트, CookingFoil 클라이언트가 이 목록을 읽습니다. 키, BIOS, RetroArch 는 들어 있지 않으며 그 폴더는 처음에 비어 있습니다.

It keeps your own files on a machine at home, reads names and icons from them, and serves the list to CyberFoil, Tinfoil-style clients and the CookingFoil client. It bundles no keys, BIOS files or RetroArch; those folders start empty.

自宅のマシンに自分のファイルを置き、ファイルから名前とアイコンを読み取って一覧として配信します。CyberFoil、Tinfoil 形式のクライアント、CookingFoil クライアントがこの一覧を読みます。キー、BIOS、RetroArch は含まれず、それらのフォルダーは最初は空です。

把自己的文件放在家里的电脑上，从文件中读取名称和图标，并以列表形式提供。CyberFoil、Tinfoil 类客户端和 CookingFoil 客户端读取这个列表。不包含密钥、BIOS 或 RetroArch，这些文件夹一开始是空的。

설치Installインストール安装

mkdir cookingfoil && cd cookingfoil
curl -O https://raw.githubusercontent.com/jshsakura/oc-cookingfoil/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/jshsakura/oc-cookingfoil/main/.env.example
mkdir -p games data keys
docker compose up -d

games 에 파일을 넣고 .env 에서 계정을 정한 뒤 실행합니다. 웹 화면은 http://<host>:9080/ 에서 열리고, 클라이언트에는 같은 주소를 서버 주소로 넣습니다. 리버스 프록시나 터널 뒤에 두는 방법은 배포 안내에 있습니다.

Put your files in games, set an account in .env, then start it. The web page opens at http://<host>:9080/, and clients take the same address as their server. Running it behind a reverse proxy or tunnel is covered in the deploy guide.

games にファイルを入れ、.env でアカウントを決めてから起動します。Web 画面は http://<host>:9080/ で開き、クライアントには同じアドレスをサーバーアドレスとして入力します。リバースプロキシやトンネルの後ろに置く方法はデプロイ手順にあります。

把文件放进 games，在 .env 中设置账号后启动。网页地址是 http://<host>:9080/，客户端填写同一地址作为服务器地址。放在反向代理或隧道后面的方法见部署说明。

하는 일What it doesできること功能

계정Accountsアカウント账号
아이디와 비밀번호로 로그인합니다. 운영자가 관리 화면에서 만들고, 구글 로그인은 설정했을 때만 나타납니다.
ID and password, created by the operator in the admin page. Google sign-in appears only when it is configured.
ID とパスワードでログインします。運営者が管理画面で作成し、Google ログインは設定したときだけ表示されます。
使用账号和密码登录，由运营者在管理页面创建。Google 登录只在配置后出现。
기기Devices本体设备
기기 화면의 QR 을 휴대폰으로 찍어 승인합니다. 승인한 기기는 언제든 끊을 수 있습니다.
Approve a console by scanning its QR code with a phone. Approved consoles can be revoked at any time.
本体に表示された QR をスマートフォンで読み取って承認します。承認した本体はいつでも解除できます。
用手机扫描主机上的二维码即可批准，已批准的主机可以随时撤销。
관리Admin管理管理
관리 화면은 관리자 비밀번호나 인증 앱 코드로 엽니다.
The admin page opens with the admin password or an authenticator code.
管理画面は管理者パスワードか認証アプリのコードで開きます。
管理页面使用管理员密码或身份验证器代码打开。
홈브류Homebrew自作アプリ自制程序
관리 화면에 등록한 GitHub 저장소의 최신 릴리스를 받아 목록에 올립니다.
Follows the GitHub repositories you add in the admin page and lists their latest releases.
管理画面に登録した GitHub リポジトリの最新リリースを取得して一覧に載せます。
跟踪在管理页面添加的 GitHub 仓库，并列出它们的最新版本。
언어Languages言語语言
웹 화면과 이름, 설명을 한국어, 영어, 일본어, 중국어로 보여줍니다.
The web page, names and descriptions come in Korean, English, Japanese and Chinese.
Web 画面、名前、説明を韓国語、英語、日本語、中国語で表示します。
网页、名称和说明支持韩语、英语、日语和中文。
