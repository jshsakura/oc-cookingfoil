compose 예시compose examplecompose の例compose 示例

services:
  cookingfoil:
    image: ghcr.io/jshsakura/oc-cookingfoil:latest
    restart: unless-stopped
    stop_grace_period: 40s
    env_file:
      - path: .env
        required: false
    ports:
      - "9080:80"
    volumes:
      - ./games:/games
      - ./data:/data
      - ./keys:/keys:ro
      - ./retro:/retro
      - ./patches:/patches
      - ./saves:/saves
      - ./homebrew:/homebrew

모든 옵션은 저장소의 docker-compose.yml 과 .env.example 에 설명되어 있고, 대부분은 관리 페이지에서 바꿀 수 있습니다.

CookingFoil 클라이언트CookingFoil clientCookingFoil クライアントCookingFoil 客户端

cookingfoil.nro 를 받아 SD 카드의 switch/ 폴더에 넣고 홈브류 메뉴에서 엽니다. 서버 주소를 넣으면 QR 이 뜹니다. 휴대폰으로 찍고 로그인해 승인합니다. 연결한 뒤에는 앱이 서버에서 스스로 업데이트하고, 홈 메뉴 바로가기도 만들 수 있습니다.

Download cookingfoil.nro, put it in the switch/ folder on the SD card and open it from the homebrew menu. Enter the server address and a QR code appears: scan it with your phone, sign in and approve. Once connected, the app updates itself from your server and can make its own HOME Menu shortcut.

cookingfoil.nro をダウンロードして SD カードの switch/ フォルダーに入れ、自作アプリのメニューから開きます。サーバーアドレスを入れると QR が出るので、スマートフォンで読み取り、サインインして承認します。接続後はアプリがサーバーから自分で更新し、HOME メニューのショートカットも作れます。

下载 cookingfoil.nro，放进 SD 卡的 switch/ 文件夹，然后从自制程序菜单打开。输入服务器地址后会出现二维码，用手机扫描、登录并批准。连接之后，应用会从你的服务器自动更新，还可以创建 HOME 菜单快捷方式。

At home you can use the server's local address with http and port 9080 instead. For the username and password, a per-console login from the Devices tab is the safer choice: it only reads the list, locks to the first console that uses it, and can be revoked at any time.

在家里也可以用服务器的内网地址、http 和端口 9080。用户名和密码建议使用在设备标签页生成的按主机登录信息，更安全：它只能读取列表，绑定到第一台使用它的主机，并且随时可以撤销。
