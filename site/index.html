CookingFoil 은 집 서버에서 도는 개인용 파일 서버입니다. 넣어 둔 파일과 홈브류 앱에 이름과 아이콘을 붙여 기기의 앱에 목록으로 보여줍니다.

CookingFoil is a personal file server that runs on your home machine. It gives the files and homebrew apps you put in it names and icons, and lists them in the app on your console.

CookingFoil は自宅のマシンで動く個人用ファイルサーバーです。入れておいたファイルと自作アプリに名前とアイコンを付け、本体のアプリに一覧で表示します。

CookingFoil 是运行在家用电脑上的个人文件服务器。它为你放入的文件和自制程序加上名称和图标，并在主机的应用中以列表显示。

기기 연결

Connecting a console

本体の接続

连接主机

  1. 기기에서 CookingFoil 을 열면 화면에 QR 이 뜹니다.Open CookingFoil on the console and it shows a QR code.本体で CookingFoil を開くと、画面に QR が表示されます。在主机上打开 CookingFoil，屏幕上会显示二维码。
  2. 휴대폰 카메라로 찍고 내 계정으로 로그인합니다.Scan it with your phone camera and sign in with your account.スマートフォンのカメラで読み取り、自分のアカウントでログインします。用手机相机扫描，并用自己的账号登录。
  3. 승인하면 그 기기만 들어옵니다. 기기에는 비밀번호가 남지 않습니다.Approve it and only that console gets in. No password is stored on it.承認するとその本体だけが接続できます。本体にパスワードは残りません。批准后只有这台主机可以连接，主机上不会保存密码。

CyberFoil 과 Tinfoil 방식 클라이언트는 설정에 서버 주소와 계정을 넣어 접속합니다.

CyberFoil and Tinfoil-style clients connect with the server address and an account in their settings.

CyberFoil と Tinfoil 形式のクライアントは、設定にサーバーアドレスとアカウントを入力して接続します。

CyberFoil 和 Tinfoil 类客户端在设置中填写服务器地址和账号即可连接。

Install

安装

Docker 가 있는 집 서버에서 실행합니다.

Run it on a home server with Docker.

Docker のある自宅サーバーで実行します。

在装有 Docker 的家用服务器上运行。

mkdir cookingfoil && cd cookingfoil
curl -O https://raw.githubusercontent.com/jshsakura/oc-cookingfoil/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/jshsakura/oc-cookingfoil/main/.env.example
mkdir -p games data keys
docker compose up -d

웹 화면은 http://<host>:9080/ 에서 열립니다. 설정 항목과 API 는 README 에 있습니다.

The web page opens at http://<host>:9080/. Settings and the API are listed in the README.

Web 画面は http://<host>:9080/ で開きます。設定項目と API は README にあります。

网页地址是 http://<host>:9080/。设置项和 API 见 README。
