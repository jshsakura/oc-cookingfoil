보안Securityセキュリティ安全

CookingFoil 은 잠긴 채로 시작하고, 켠 것만 엽니다. 서버를 밖에 열기 전에 아래 여섯 가지를 확인합니다.

CookingFoil starts locked and opens only what you turn on. Check these six things before you open the server to the outside.

CookingFoil はロックされた状態で始まり、オンにしたものだけを開きます。サーバーを外に公開する前に、次の 6 つを確かめてください。

CookingFoil 以锁定状态启动，只开放你开启的功能。在把服务器开放到外部之前，请确认下面六点。

콘솔은 키로만 붙습니다Consoles connect by key only本体はキーだけで接続主机只用密钥连接

기기에는 비밀번호가 남지 않습니다. CookingFoil 클라이언트는 기기마다 따로 거둘 수 있는 자기 키로만 연결합니다.

No password is ever stored on a console. The CookingFoil client connects with a key of its own that you can revoke alone.

本体にパスワードは残りません。CookingFoil クライアントは、個別に取り消せる自分のキーだけで接続します。

主机上不会保存密码。CookingFoil 客户端只用各自可单独撤销的密钥连接。

관리 페이지는 2단계 인증A second factor for the admin管理ページは 2 要素認証管理页面使用第二因素

로그인 위에 인증 앱 코드를 한 번 더 묻습니다. 코드를 여러 번 틀리면 계정과 주소를 잠급니다.

The admin page asks for an authenticator code on top of the sign-in. Repeated wrong codes lock the account and the address.

サインインに加えて認証アプリのコードを求めます。間違え続けると、アカウントとアドレスをロックします。

在登录之外再要求身份验证器代码。多次输错会锁定账号和地址。

밖에서는 HTTPS 로HTTPS from outside外からは HTTPS で外部访问走 HTTPS

HTTPS 를 처리하는 리버스 프록시나 터널 뒤에 두고, COOK_TRUST_PROXY 에는 그 프록시 구간만 넣습니다.

Put the server behind a reverse proxy or tunnel that terminates HTTPS, and set COOK_TRUST_PROXY to its hops only.

HTTPS を終端するリバースプロキシかトンネルの後ろに置き、COOK_TRUST_PROXY にはそのプロキシの経路だけを入れます。

把服务器放在终止 HTTPS 的反向代理或隧道后面，COOK_TRUST_PROXY 只填写这个代理的跳点。

승인 방식은 알고 고릅니다Approval on purpose承認方法は理解して選ぶ有意识地选择批准方式

관리자가 하나씩 승인하거나, 로그인한 기기만 바로 승인합니다. 모두 승인은 내 기기만 닿는 서버에서만 씁니다.

Approve consoles by hand, or only the ones that sign in. Approving every console is only for a server nothing else can reach.

管理者が 1 台ずつ承認するか、サインインした本体だけをすぐ承認します。すべて承認は、自分の本体しか届かないサーバーでだけ使います。

집 안의 평문 HTTPPlain HTTP at home自宅での平文 HTTP家庭网络中的明文 HTTP

http:// 로 붙으면 비밀번호와 토큰이 암호화되지 않은 채 네트워크를 지나갑니다. 세션 토큰은 12시간 뒤에 끝나고 기기 키에 묶여 피해를 줄이지만, 막지는 못합니다. 나 혼자 쓰는 네트워크가 아니라면 HTTPS 를 씁니다.

Over http://, passwords and tokens cross the network unencrypted. Session tokens end after 12 hours and are tied to the console's device key, which narrows the damage but does not prevent it. Use HTTPS whenever the network is not yours alone.

http:// で接続すると、パスワードとトークンは暗号化されずにネットワークを流れます。セッショントークンは 12 時間で切れ、本体のデバイスキーに結び付いているので被害は狭まりますが、防げるわけではありません。自分だけのネットワークでなければ HTTPS を使ってください。

通过 http:// 连接时，密码和令牌会以未加密的形式经过网络。会话令牌 12 小时后失效并绑定设备密钥，能缩小损失，但无法阻止。只要网络不是你一个人在用，就请使用 HTTPS。

비밀번호와 기기 키는 해시로만 남기고, 서버가 다시 읽어야 하는 비밀값은 .env 의 COOK_SECRET_KEY 로 암호화해 둡니다. 데이터 폴더만 복사해 가서는 열 수 없습니다. 키는 따로 보관합니다.

Passwords and console keys are kept as hashes only, and the secrets the server reads back are sealed with COOK_SECRET_KEY from .env. A copy of the data folder alone opens none of them. Keep a copy of the key.

パスワードと本体のキーはハッシュだけを残し、サーバーが読み戻す秘密情報は .env の COOK_SECRET_KEY で暗号化します。データフォルダだけをコピーしても開けません。キーは別に保管してください。

密码和主机密钥只保存哈希，服务器需要读回的密钥类信息用 .env 中的 COOK_SECRET_KEY 加密。只复制数据目录无法打开它们。请另外保存这个密钥。
