기기에서 실행하는 앱입니다. 받은 파일을 SD 카드의 switch/ 폴더에 넣고 홈브류 메뉴에서 엽니다. 연결한 뒤에는 앱이 서버에서 새 버전을 받아 스스로 업데이트합니다.

The app you run on the console. Put the file in the switch/ folder on the SD card and open it from the homebrew menu. Once connected, the app updates itself from your server.

本体で動かすアプリです。ダウンロードしたファイルを SD カードの switch/ フォルダーに入れ、自作アプリのメニューから開きます。接続後はアプリがサーバーから新しいバージョンを受け取って自分で更新します。

在主机上运行的应用。把下载的文件放进 SD 卡的 switch/ 文件夹，然后从自制程序菜单打开。连接之后，应用会从你的服务器下载新版本并自动更新。

처음 띄운 뒤 docker compose logs cookingfoil 에 나오는 설정 코드로 http://서버주소:9080/setup 에서 관리자 계정을 만듭니다. 전체 옵션은 저장소의 docker-compose.yml 과 .env.example 에 있습니다.

After the first start, take the setup code from docker compose logs cookingfoil and create the admin account at http://your-server:9080/setup. Every option is in the repository's docker-compose.yml and .env.example.

初回起動後、docker compose logs cookingfoil に出るセットアップコードで http://サーバーアドレス:9080/setup から管理者アカウントを作ります。すべてのオプションはリポジトリの docker-compose.yml と .env.example にあります。

首次启动后，用 docker compose logs cookingfoil 中的设置码，在 http://服务器地址:9080/setup 创建管理员账号。全部选项见仓库的 docker-compose.yml 和 .env.example。

집 안에서는 호스트에 서버의 내부 주소, 프로토콜에 http, 포트에 9080 을 넣어도 됩니다. CookingFoil 앱은 연결한 뒤 앱 안에서 홈 메뉴 바로가기를 만들 수 있어, 홈브류 메뉴를 거치지 않고 바로 엽니다.

At home you can use the server's local address with http and port 9080 instead. Once connected, the CookingFoil app can make its own HOME Menu shortcut, so it opens straight from the HOME Menu.

自宅ではホストにサーバーの内部アドレス、プロトコルに http、ポートに 9080 を入れても使えます。CookingFoil アプリは接続後、アプリ内で HOME メニューのショートカットを作れるので、自作アプリのメニューを通らずに直接開けます。

在家里也可以把主机填成服务器的内网地址，协议用 http，端口用 9080。连接后，CookingFoil 应用可以在应用内创建 HOME 菜单快捷方式，不经过自制程序菜单就能直接打开。
