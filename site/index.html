FROM YOUR SERVER TO YOUR CONSOLE

自分のサーバーから、本体へ

从你的服务器，到你的主机

넣어 두면 정리되고,
고르면 설치됩니다. Keep your files.
Enjoy your library. ファイルを置いたら、
本体で選ぶだけ。 文件放好，
在主机上选就行。

파일의 이름과 업데이트를 챙기는 서버, 설치와 세이브를 관리하는 클라이언트. CookingFoil이 둘을 이어 줍니다.

A server that keeps your files in order. A client that handles installs, updates and saves. CookingFoil brings them together.

名前や更新を整理するサーバーと、インストールやセーブを扱うクライアント。CookingFoil がつなぎます。

服务器整理名称与更新，客户端管理安装与存档。CookingFoil 把两端连起来。

Actual English UI with sample data. Missing icons use the app’s native first-letter tiles.

サンプルデータで動かした実際の英語 UI です。アイコンがない項目は、アプリ本来の頭文字タイルで表示しています。

파일을 옮기는 일에서,
즐길 것을 고르는 일로. Less file handling.
More choosing what to play. ファイルの手間を減らして、
遊ぶものを選ぶ時間へ。 少些文件整理，

  1. 01

    서버에 파일을 넣습니다. Put files on your server. サーバーにファイルを置く。 把文件放在服务器上。

    incoming 폴더에 넣으면 종류에 맞게 정리합니다. 이름과 아이콘을 찾고, 본편·업데이트·DLC를 게임별로 묶습니다.

    Drop files into incoming. The server sorts them by type, looks up names and icons, and groups base, updates and DLC by game.

    incoming に置くと種類に合わせて整理。名前とアイコンを調べ、本編・更新・DLC をゲームごとにまとめます。

    放入 incoming 文件夹后自动按类型整理，查找名称与图标，并按游戏归类本体、更新与 DLC。

  2. 02

    QR로 본체를 연결합니다. Approve your console by QR. QR で本体を承認。 扫码批准主机。

    본체에 뜬 QR을 휴대폰으로 찍고 승인합니다. 이후에는 기기에 저장된 접근 키로 연결됩니다.

    Scan the console’s QR code on your phone and approve it. The client reconnects using its saved access key.

    本体の QR をスマートフォンで読み取って承認。次からは保存したアクセスキーで接続します。

    用手机扫描主机上的二维码并批准，之后客户端会使用保存的访问密钥连接。

  3. 03

    본체에서 골라 설치합니다. Choose and install on the console. 本体で選んでインストール。 在主机上选择并安装。

    검색하고, 업데이트와 DLC를 골라 대기열에 넣습니다. SD 카드와 본체 저장 공간 중 설치할 곳도 고릅니다.

    Search your library, choose updates and DLC, and queue them. Pick SD card or console storage as the destination.

    検索し、必要な更新と DLC を選んでキューへ。SD カードと本体保存メモリーから保存先を選べます。

    搜索资料库，选择更新与 DLC 后加入队列，并选择 SD 卡或主机存储。

Find a game, read its details and size, then select the files you need. Browse several servers together and choose where a download comes from.

ゲームの説明と容量を確認して必要なファイルを選択。複数のサーバーもまとめて見て、ダウンロード元を選べます。

找到游戏，查看说明与容量，只选择需要的文件。多个服务器的列表也能一起浏览，并选择下载来源。

끊겨도 이어 받고,
업데이트도 놓치지 않게. An interrupted download

다운로드 대기열과 기록을 남기고, 지원되는 다운로드는 중단 지점부터 이어 받습니다. 설치된 버전과 서버의 버전을 비교해 업데이트도 따로 모아 보여 줍니다.

The queue and download history are saved. Supported downloads continue from their saved position, and installed versions are compared with the server to surface updates.

キューと履歴を保存し、対応するダウンロードは中断した位置から再開。インストール済みとサーバーのバージョンを比べ、更新をまとめます。

队列与下载记录会保存，支持的下载可从中断位置继续。对比已安装版本与服务器版本，集中显示更新。

받는 동안에는 본체가 절전 모드로 들어가지 않습니다.

The console stays awake while downloading.

ダウンロード中は本体がスリープしません。

下载期间主机保持唤醒。

홈브루 Homebrew 自作アプリ 自制程序

서버에 GitHub 저장소를 등록하면 새 릴리스를 받아 둡니다. 본체에서는 NRO와 앱 폴더를 설치하고, 업데이트를 확인합니다.

Register a GitHub repository on the server to collect new releases. Install NROs or app folders and check for updates on the console.

サーバーに GitHub リポジトリを登録して新しいリリースを取得。本体で NRO やアプリフォルダーをインストールし、更新を確認できます。

在服务器登记 GitHub 仓库以获取新版本，再在主机上安装 NRO 或应用文件夹并检查更新。

세이브 Saves セーブ 存档

사용자별로 백업하고 복원합니다. 서버의 세이브를 가져오거나 Dropbox에 보관할 수 있고, 복원 전에는 되돌림용 백업을 만듭니다.

Back up and restore per-user saves, import server saves or keep backups on Dropbox. A rollback backup is made before a restore.

ユーザーごとにバックアップと復元。サーバーからの取り込みや Dropbox への保存にも対応し、復元前には戻すためのコピーを作ります。

按用户备份与恢复，导入服务器存档，或将备份保存在 Dropbox。恢复前会创建回退备份。

패치 Patches パッチ 补丁

게임 파일, 치트, IPS, FPSLocker 패치를 켜고 끕니다. 파일 충돌을 확인하고, 치트를 합칠 때 원래 사용하던 내용도 보존합니다.

Enable or disable game file, cheat, IPS and FPSLocker patches. File conflicts are checked, and your original cheats are preserved when merging.

ゲームファイル、チート、IPS、FPSLocker パッチを切り替え。ファイルの競合を確認し、チートの統合では元の内容も残します。

启用或停用游戏文件、金手指、IPS 与 FPSLocker 补丁。检查文件冲突，合并时保留原有金手指。

레트로 Retro レトロ 复古游戏

시스템별로 라이브러리를 둘러보고 필요한 묶음을 받습니다. 직접 준비한 RetroArch 팩과 게임, 지원되는 바로가기를 연결합니다.

Browse by system and download the bundles you need. Use your own server-provided RetroArch packs, games and supported shortcuts.

システム別に探して必要なセットをダウンロード。自分で用意した RetroArch パックやゲーム、対応するショートカットを使えます。

按系统浏览并下载所需的文件包，使用自己准备的 RetroArch 包、游戏及支持的快捷方式。

관련 콘텐츠와 서버 설정이 있을 때 기능이 표시됩니다. 세이브와 패치 적용은 사용자가 선택합니다.

Features appear when the server offers the required content and configuration. You choose when to apply saves and patches.

必要なコンテンツとサーバー設定がある機能が表示されます。セーブやパッチを適用するかは自分で選びます。

服务器提供相应内容与配置时才显示相关功能。是否应用存档与补丁由你选择。

GET STARTED

서버 하나, 앱 하나.
여기서 시작합니다. One server. One app.
Start here. サーバーとアプリを、
ひとつずつ。 一个服务器，一个应用。
从这里开始。

  1. 서버를 띄웁니다. Start your server. サーバーを起動。 启动服务器。

    저장소의 Compose 파일과 설정 예시를 받아 실행합니다. 처음 접속하면 관리자 설정으로 이어집니다.

    Get the Compose file and example settings from the repository. On the first visit, the server walks you through admin setup.

    リポジトリの Compose ファイルと設定例で起動。初回アクセス時に管理者の設定へ進みます。

    从仓库获取 Compose 文件和示例配置并启动，首次访问时会引导完成管理员设置。

    서버 설치 안내 Server setup guide サーバーの設置方法 服务器安装指南

  2. 서버에서 앱을 받습니다. Get the app from your server. サーバーからアプリを入手。 从服务器获取应用。

    서버 웹페이지에 로그인해 cookingfoil.nro를 받고 switch/cookingfoil/에 복사합니다. 서버에 클라이언트 빌드가 준비되어 있어야 합니다.

    Sign in to your server’s web page, download cookingfoil.nro and copy it to switch/cookingfoil/. The operator must provide a client build first.

    サーバーの Web ページにログインし、cookingfoil.nro を入手して switch/cookingfoil/ にコピー。管理者がビルドを用意している必要があります。

    登录服务器网页，下载 cookingfoil.nro 并复制到 switch/cookingfoil/。管理员需要先提供客户端构建。

    본체 연결 방법 Client connection guide 最新の本体を接続 客户端连接指南

이미 서버가 있나요? 사용 권한이 있는 서버 주소만 앱에 추가하면 됩니다. 홈브루를 실행할 수 있는 본체가 필요합니다.

Already have a server? Add its address in the app. Use a server you have permission to access and a console that can run homebrew.

すでにサーバーがあれば、利用できるアドレスをアプリに追加するだけ。自作アプリを実行できる本体が必要です。

已有服务器？在应用中添加有权访问的服务器地址即可。主机需要能够运行自制程序。

서버에서 받은 클라이언트에는 연결에 필요한 설정을 담을 수 있습니다. 직접 서버를 추가했다면 본체의 QR을 휴대폰으로 찍고 승인합니다. 승인 뒤에는 본체의 접근 키로 연결하므로 계정 비밀번호를 본체에 남길 필요가 없습니다.

A client downloaded from your server can carry its connection settings. If you add a server manually, scan the console’s QR code on your phone and approve it. After approval, the console uses its access key without keeping your account password.

サーバーから入手したクライアントには接続設定を含められます。手動で追加した場合は本体の QR をスマートフォンで承認。次からはアクセスキーを使い、本体にアカウントのパスワードを残しません。

从服务器下载的客户端可以包含连接配置。手动添加服务器时，用手机扫码批准。批准后主机使用访问密钥连接，无需保留账号密码。

CyberFoil과 Tinfoil 방식 클라이언트도 서버에 연결할 수 있습니다. 연결 방식은 서버 안내에서 확인합니다.

CyberFoil and Tinfoil-style clients can also connect. See the server guide for their connection methods.

CyberFoil や Tinfoil 形式のクライアントも接続できます。方法はサーバーの案内を確認してください。

CyberFoil 和 Tinfoil 类客户端也能连接，具体方式见服务器指南。

서버 로그의 코드로 처음 설정을 시작하고, 계정과 기기를 승인합니다. 필요하면 기기별 접근을 거둘 수 있습니다. 외부에서 연결할 때는 HTTPS를 준비하고, 서버의 보안 안내를 확인합니다.

Start setup with the code from your server log, then approve accounts and consoles. Revoke a console’s access when needed. Set up HTTPS for outside access and read the server’s security guide.

サーバーログのコードで初期設定し、アカウントと本体を承認。必要なときは本体ごとに接続を取り消せます。外部からの接続には HTTPS を用意し、セキュリティガイドを確認してください。

使用服务器日志中的代码开始设置，批准账号与主机，需要时按主机撤销访问。外部连接请配置 HTTPS 并阅读服务器安全指南。
