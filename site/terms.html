CookingFoil 소개What it is概要简介

CookingFoil 은 개인이 자기 서버에 직접 설치해서 쓰는 홈브류 파일 서버입니다. 누구나 들어오는 공개 서비스가 아니고, 서버마다 그 서버를 설치한 운영자가 관리합니다.

CookingFoil is a homebrew file server people install on their own servers. It is not a public service; each server is run by its operator.

CookingFoil は個人が自分のサーバーにインストールして使う自作アプリ向けファイルサーバーです。公開サービスではなく、各サーバーはその運営者が管理します。

CookingFoil 是个人安装在自己服务器上使用的自制程序文件服务器。它不是公开服务，每台服务器由其运营者管理。
